# 💡 Interactive Light Bulb Toggle

An interactive web application built using **HTML**, **CSS**, and **JavaScript** that simulates switching a light bulb on and off. The project includes a creative cat animation that reacts to the lighting state, making it a fun beginner-friendly JavaScript project.

---

## 📖 About the Project

This project demonstrates DOM manipulation and event handling in JavaScript by allowing users to control a virtual light switch.

When the light is turned:

- 🟢 **ON**
  - The bulb glows.
  - The cat becomes visible.
  - The switch changes to the ON state.

- 🔴 **OFF**
  - The bulb turns off.
  - The cat disappears into the darkness, leaving only its glowing eyes visible.
  - The switch changes to the OFF state.
